## Project Description
This is a React Native Travel Guide application built using Expo and React Navigation.
The app demonstrates multi-screen navigation using Stack and Bottom Tab navigators.
Users can explore destinations and view details for each place.

## Features
- Stack Navigation (Home → Details)
- Bottom Tab Navigation (Explore & Settings)
- Passing data between screens
- Custom header styling
- Tab icons using Ionicons

## Screens
- Home Screen
- Details Screen
- Settings Screen

## Technologies Used
- React Native
- Expo
- React Navigation
